# DevInspector PHP SDK

SDK oficial do DevInspector para PHP e Laravel.

**Versão:** 3.0.0

O SDK fornece monitoramento de erros, métricas de requisições, APM, consultas de banco de dados, tracing distribuído, identificação de release e captura automática de exceções.

## Requisitos

- PHP 8.1 ou superior
- Extensão `curl`
- Extensão `json`
- Extensão `mbstring`
- Laravel para utilização do middleware

## Instalação

```bash
composer require devinspector/audit-sdk
